# Horosa 星阙 v3.11.0

本版是 **AI 助手的一次大版本升级**:对话助手从「单轮问答」升级为可自动化、可连接外部工具的智能体形态;同时对 AI 挂载链做了一次逐技法自检修复,并补齐择日、排盘、时间录入与稳定性方面的多处改进。**所有新增能力默认关闭,不开启时行为与上一版一致。**

## AI 助手 · 行动能力(总开关默认关)

- **让 AI 操控软件**:开启后,AI 可按你的明确要求新建命盘/事盘、无头起盘、修改排盘口径与显示偏好、切换技法页、合盘配对、载入工作区;只读或只增,永不删除覆盖。
- **审批三档 + 类别收紧 + 信任档案**:全自动(可撤销)/ 每次确认 / 只读;查询、外部工具、反问、界面操作四类可单独设得更严;信任的档案免确认。AI 缺信息时会向你反问,而不是空转或臆造。
- **动作账本与撤销**:所有写入(含外部软件来源)进账本,可一键撤销;账本写不进本机存储时拒绝执行;写入前先看 before→after 差异;按工具名放行/禁用。
- **任务中心与通知**:目标任务(一句话目标自动多轮推进,可暂停/纠偏/预算封顶)、定时任务(每日简报 / 每月流年 / 择日到期提醒 / 自定义提示词,错过按策略跳过或补跑)、自动化规则(当 X 发生自动做 Y,防自激、每事件上限、冷却);macOS 桌面通知(默认关,限流去重);任务中心除右下角铃铛外,进阶页「行动能力」卡与 `/任务` 命令都可直达。

## AI 助手 · 对话效率与记忆

- **斜杠命令与技能包**:输入框首字符 `/` 弹出命令面板(按「盘面与分析 / 会话 / 模型与协作 / 技能」分组,缺前提或开关未开的命令灰显并写明原因;中文输入法组合期不抢键);`/择日 奇门` 一类直达择日子页,`/合盘 @对方` 可用 @ 引用,新增 `/命主`(命主工作区)与 `/任务`(任务中心);技能包把技法、内容段、口径、模板、参数打成一个单元,可导出导入;应用内手册列出全部命令。
- **`@` 引用**:命盘 / 事盘 / 资料 / 组合 / 模板 / 技法 / 技法段分组显示;技法候选一条不截,全部命盘类与事盘类技法按术数域分组列出(不适用当前案例的灰显并在发送时提示),`@技法名/` 直接列出该技法的内容段(英文键与拼音也行,如 `@zw/命`;有关键字时默认高亮最匹配的一项),支持中文、英文键与拼音首字母搜索(如 `@qm` 找奇门遁甲),同名按尾号消歧。
- **对话压缩 `/compact`、旁问 `/side`、回退到某一轮**(先撤销 AI 动作再恢复设置,可改为分支保留原线)。
- **个人口径**(`/init` 生成草稿)、**事实记忆**(候选 → 确认 → 入库,按本人/命主/全局分组;与排盘冲突以排盘为准)、**命主工作区**。
- **常驻状态栏**:模型 · 审批档 · 挂载字数/预算 · 本会话费用 · 缓存命中 · 上下文占用 · 策略档 · 已压缩条数(点击查看摘要正文)。
- **对话上下文策略**三预设(不裁 / 窗口 / 经济)+ 细项;缺省改为「窗口」(长对话成本更低、缓存命中更高,可一键切回「不裁」);**挂载字数预算**可自定。

## AI 助手 · 多模型与协作

- **`/多模型`**:同一问题并排 2–4 路对比,判官打分或合并为一稿,发送前显示预估费用。
- **`/审阅`**:优先用另一家模型对拍挂载数据挑错(错误 / 夸大 / 漏项 / 无依据),可一键按批注重写,原稿保留。
- **`/编排`**:复杂问题拆给多个技法并行分析(子任务只读、只挂本技法数据),综合答案并标注分歧。
- **按任务用模型**六槽(工具轮 / 终稿 / 判官 / 审阅 / 规划 / 子任务),每槽可单独设推理档、温度、输出上限与具名方案;**结构化输出** json_schema 严格模式四家族翻译,不支持时自动降级。
