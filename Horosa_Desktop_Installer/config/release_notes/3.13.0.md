# Horosa 星阙 v3.13.0

本版以**主限法的全面重做**为主:各方位法、世俗(In Mundo)各法与新增的 Field Plane 方向类别全部按几何定义重写,新增 Horizontal / Koch 两种方位法,受影响的方法在「弧算法」下拉里分「（改进）」(严格几何,缺省)与「（经典）」(传统程序的写法)两项;度数换算(时间钥匙)扩到 38 档并逐档按定义落地;新增一批取点与方向设置,当前组合下不起作用的设置一律置灰并说明原因。星运的多重回归、界推运、129 年系统、Balbillus、年龄推进点、月相推运改为精确算法;量化盘新增中点赤经 / 赤纬坐标、公式求解、次限推运层与更多盘基;另有 AI 模型清单更新、繁体界面用字订正与后端存活探针修复。**会改变已有盘结果的地方,各节里都标了「结果会变」。**

## 星运 · 主限法

**方位法(弧算法)全部按定义重写 —— 结果会变**
- **Placidus(半弧法)**:应星沿自身周日圈走到迫星相位点的半弧比例位置;子午距一律取真实时角,地平之上从中天量、除以昼半弧,地平之下从天底量、除以夜半弧。
- **Regiomontanus / Campanus(极下法)**:位置圈的极取自迫星相位点,应星在同一极下求斜升 / 斜降,弧带正负。
- **Morinus**:位置圈改为过黄极与迫星相位点的黄经圈,应星沿自身赤纬圈走到圈上(弧与地理纬度无关)。
- **Edmund Jones**:每组(迫星、应星、相位)只出一行,按年龄窗在赤经式与半弧式之间二选一;弧不分方向,顺 / 逆勾选不再把整表筛空。
- **Along-Ecliptic**:轴应星改走周日旋转弧;本体相位取在应星一侧;相位点跨白羊 0° 的行不再被显示窗误删。
- 以上各法补回映点、赤纬平行、界与超过 180 年的整圈复发行。
- 几何修正:半弧、极下、世俗位置的判定改为严格几何,同一张盘的结果不再随「赤经 0° 落在哪里」而变(此前高纬盘约两到四成的行会算错)。

**新方位法**
- **Horizontal(地平经圈)**:位置圈为过天顶与目标点的地平经圈,按方位角求交。
- **Koch(出生地)**:位置圈为过目标点的出生地斜升圈。
- 两法都有世俗(In Mundo)版本、世俗子午 / 地平平行与急动平行;主限天球画出各自的位置圈,极点列给出极。

**世俗(In Mundo)各法重做 —— 结果会变**
- Alcabitius:世俗位置按上升点半弧的时圈分宫;上升 / 下降 / 宿命点 / 新增「反宿命点」(卯酉圈东交点)/ 天顶 / 天底六个轴应星按迫星穿越地平、卯酉圈或子午圈的弧计算。世俗盘缺省带天底、下降与反宿命点。
- Placidus / Meridian / Morinus / Regiomontanus / Campanus / Porphyry / Equal(黄道)/ Equal(时圈):各按本法的世俗位置定义重写,六轴应星共用同一套穿越弧。
- 世俗子午平行按定义重做(Placidus 用半弧比例镜像,位置圈各法用世俗角镜像,其余用赤经镜像);世俗地平平行与急动平行按各方位法自身的度量镜像。

**新方向类别 Field Plane(场平面制)**
- 「方向」下拉新增 Field Plane:相位点黄经照常取,黄纬借用该星出生后第一次真正走到这个黄经时的黄纬;合相点用本命黄纬。主限法表、主限法盘、主限天球、AI 挂载与导出全链可用。

**「改进 / 经典」两种写法**
- 在「弧算法」下拉里,两种写法结果确有不同的方法各列两项:「（改进）」= 严格球面几何(缺省),「（经典）」= 传统程序的写法(如东西按赤经数值直接判定、不跨 0° 回绕)。涉及:黄道 Placidus / Regiomontanus / Campanus / Edmund Jones / Topocentric / Horizontal / Koch,世俗 Placidus / Regiomontanus / Campanus / Porphyry 等,以及开世俗平行时的 Morinus 与 Meridian / Equal 宫制下的 Ptolemy;Field Plane 各法同样分两项(经典写法下合相点也借用黄纬)。帮助手册「改进与经典」一节逐项列出。

**度数换算(时间钥匙)扩到 38 档,逐档按定义落地 —— 结果会变**
- 表格(弧 → 年)与主限法盘(年 → 弧)共用同一个换算出口,逐档互逆;Ptolemy(缺省)与以往逐位相同。
- 真太阳弧 / Van Dam:正负弧都看出生后太阳走过的赤经;新增设置「逆向弧用出生前太阳」。
- Simmonite = 出生当天 0 时至次日 0 时太阳的赤经行度;新增「生日黄经日行」。Kepler 与 Brahe = 出生前后两个真午夜之间太阳的赤经行度。
- Ascendant-arc 改为上升弧计时,新增 Vertical-arc(宿命点);新增 Septenary(30°/7)、Sub-Duodenary(12′30″)、Symbolic Week(1° = 7 年);Novenary 改 30°/9,Symbolic Moon 改月亮平均日行 13°10′35″,Cardano / Umar / Synodic Year / Symbolic Year / Plantiko / Self-Measure 改为精确分式。
- 新增 7 档「（经典）」:真太阳弧(平黄赤交角)、Kepler / Brahe(出生后一日)、Wöllner、Synodic Year、Novenary、Symbolic Moon 的传统截断常数,紧跟在各自的精确档后面。
- 下拉按类排列,主限法表、主限法盘与 AI 挂载读同一份清单。

**新设置(扩展弹层「取点与方向」等;缺省与以往逐位相同)**
- 相位侧(只出右旋 / 只出左旋)、忽略应星黄纬、忽略迫星黄纬、传统逆向(缺省开)、月亮视差、真位置。
- **相位点黄纬**(黄道制迫星的相位点):在黄道上(缺省)/ 合冲带黄纬 / 余弦递减(正切式)/ 线性递减 / 按宫位(按所选方位法的宫位度量保持与迫星本体相同的偏移)。
- **日期年长**:实际天数(缺省,与以往相同)/ 365 · 366 定长年(年内零头按定长年折日,两档最多差 1 天)。
- **恒星迫星**:与行星同一套相位(左右相位行齐全),表格、AI 快照、主限天球同源;天球恒星名牌统一英文名。
- 流派预设新增 **Gouchon** 档(Regiomontanus 黄道主限 × 真太阳弧 × 顺逆双开 × 合冲带黄纬),预设扩到九维。
- **不起作用的设置置灰并说明**:在当前「盘类 × 弧算法」组合下对结果没有影响的设置(如经典口径 Field Plane 下的「忽略迫星黄纬」、黄道相位点在黄道上时的「忽略迫星黄纬」、部分方位法下的下降 / 天底扩展)置灰,悬停写明原因;对应规则与引擎逐组合实测一致。

**修正**
- 主限法盘的「推运方法」改为与主限法表同一套「弧算法(改进 / 经典)+ 盘面宫制」;外圈宫头按所选宫制,此前方法停在缺省时宫制一律被打回 Alcabitius。

## 星运 · 其他技法(结果会变)

- **多重回归**:第 n 回按「黄经走满 n 圈回到本命黄经」精确求解,逆行三过归为同一回并标「共 N 过 · 首过」;恒星黄道盘按恒星黄道求、月交随本盘真 / 平交点(此前恒星盘差约 n×20 分钟、平交点盘差约 53 天;水星 / 金星此前找的不是回归);找不到如实写「范围内未找到」。星体扩到日月五星、天海冥与月交,可选回数。
- **界推运**:方向改为顺黄道(此前序列倒走、出生所在之界那段缺失);新增发放点(四轴 / 七星 / 天海冥 / 北交 / 宿命点 / 福点 / 精神点 / 产前朔望)、时间算法(上升时间 / 斜升差 / 一度一年)、年长与年限四项选择;星座上升时间按出生纬度与当日交角精算;新增伙伴星期表。
- **129 年系统**:起始星、次序(本命黄经序 / 迦勒底序)、年制六档、子限铺法三档可选;页面改为两层树,带起始日期与时长。
- **Balbillus**:一级时长按序数度离擢升度的角距精确计算(删去拟合系数);子限铺法三档、年制六档可选;星名带落宫注记。
- **年龄推进点**:推进方式(Koch 宫 / 等速 5°/年)、事件范围、年长、年限可选;「全部点 × 五相位」时关键岁数摘要只列合 / 冲,其余见逐岁表。
- **月相推运**:按星历精算月日相位角。
- AI 挂载:界推运发放点、年龄推进点推进方式、Balbillus、129 年系统、十年期、三分主星、小限交点等 14 个技法的口径,缺省跟随星运页保存的设置(没改过 = 出厂默认,与以往相同)。

- **盘基新增五档**:H5 72° / H7 51°25′43″ / H9 40° / H10 36° / H32 11°15′(共 22 档;缺省 90° 不变)。
- **中点坐标**:行星中点页左栏(与分宫制同一行)可选 黄经(缺省)/ 赤经 / 赤纬。赤经:两点赤经的近轴中点及落在其上的合 / 刑 / 冲;赤纬:两点赤纬的平均及与之平行(∥)/ 反平行(⥮)的星体;坐标按出生时刻真黄赤交角换算。两表与黄经表同一版式(星体符号、分组卡片)。AI 快照与导出新增「中点坐标」段,AI 挂载齿轮也可单独选。
