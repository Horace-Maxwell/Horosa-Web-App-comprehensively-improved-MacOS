# v3.3.0
- 新技法「一掌经」(命→其他):十二支坐十二星、归六道断吉凶;顺逆规则/命宫定法/大限运长与起运/小限起宫/流年十二神/重犯口诀/定月法等多流派开关即改即算;神煞合参层按本盘实算落宫(仅列命中,非全表罗列);紫微式大格盘+金色主题;AI 导出/分析挂载全接线;排盘经古本例逐字校验。
- 合盘「关系量化」升级:天体分档加权(七星与四轴主导、婚神次之、其余小行星与虚点大幅降权),分数更能区分主星联结;量化结果并入 AI 分析与导出。
- 命盘管理载入全字段还原:选择已存命例后,保存时的性别与全部排盘选项(宫制/黄道/恒星制/界系/七政四余/印度占星/主限法视图/容许度等)完整生效,不再沿用上一张盘的设置;数算与其他技法(邵子/铁板/河洛/策天/一掌经等)载入命例即时随记录刷新性别与农历锚点,技法内手动切换不受干扰。
- 排盘坐标格式全兼容:十进制坐标(31.2)/度分坐标(31n12)/数值坐标一律正确解析,不再出现「param error」;异常坐标给出明确提示。
- 奇门遁甲:时家拆补法/置闰法两处定局错局根治,与参考引擎全矩阵逐点核对无差。
- 六壬:课名词汇增强——伏吟按课经细分四格,别责补别名,三传结果不变。
- 本地服务连接更稳:启动时身份握手校验,端口被其它程序占用或串台时自动重新协商正确端口,不再误报「服务未就绪」。
- AI 分析挂载与导出全技法审计修复:辅盘导出归位、六壬/金口诀事盘设置完整回放、印度占星挂载分盘可调、界推运与年龄推进点导出为空修复等。
- 界面:左栏支持一键全宽展开(全技法通用),窄栏选项不再被遮挡。
- 运行时随版本号同步为 3.3.0-runtime1。
