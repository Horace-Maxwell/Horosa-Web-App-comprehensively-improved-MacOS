# v3.7.0

## 新功能

### 天星择日 · 征象搜索(全新模块)
- 工具组新增「择日搜索」主导航页:在任意时间范围内按天象条件正向搜索吉时
- 32 类搜索条件引擎:相位(入相/出相/正相位三口径)、落座、落宫、恒星合(制减岁差)、月相、空亡、燃烧、逆行、二十八宿、行星时等,支持与/或/非/异或区间组合
- 四区工作台:条件编排区、时间轴结果区、命中区间表、点击跳盘联动
- 每个命中区间带 explain 判读(为什么此段命中)、概览浮窗与双时刻精选(区间首/峰值)
- 结果与主排盘完全同步(含宫头前移 5° 律全链一致)

### 卜卦判读引擎 · 三处修复
- 「映点参与判读」开关真接线:此前恒开不受控,现关闭后映点促成即停用
- 「同主一星」判读卡修复:命主与事项主同星时,A-E 五种裁决法的判读卡此前恒不显示,现正常呈现
- 「燃烧限同座」真实现(1647 主流口径):燃烧/日心须与太阳同座,异座近日自动按「日光束下」论;择日同步生效

### 奇门遁甲 · 置闰定局修正
- 置闰法改用至点锚框架:以二至日与其前最近上元符头的日距判闰,修正 1993/1996/2016 芒种、1998/2018 大雪等年份整段错一节气块并产生跨年断局的问题
- 置闰天数选项语义更新:满 9 天即闰(默认·主流)/满 8 天即闰(从宽)
