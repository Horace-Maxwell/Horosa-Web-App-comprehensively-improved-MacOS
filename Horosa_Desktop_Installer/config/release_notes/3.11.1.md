# Horosa 星阙 v3.11.1

本版是 v3.11.0 之后的一次修正版:**界面切换明暗主题后,所有技法的盘面都随之重画**;排盘设置新增「新命盘的缺省口径 = 上次亲手设的值」;修掉上一版排盘设置保留机制的几处遗留;安装器与更新链的两处既有问题根治。

---

## 盘面随界面主题重画

- **切换明暗主题后,所有以图形绘制的盘面都随之换色**:占星单盘 / 双盘 / 三维天球、紫微、宿盘、二十八宿、七政、六壬、卦占、金口诀、卜卦盘、汉堡学派五种盘、玄史地图、占星地图等。此前只有少数盘面会跟着变,宿盘等在暗色界面里仍是宣纸白底加深色墨。
- **底色对了、墨色也对了**:宿盘 / 二十八宿 / 六壬 / 卦占 / 金口诀 / 卜卦盘的线条与文字颜色此前固化在常量表或绘图对象里,切主题后重画也换不掉(暗底上仍是浅色主题的深灰墨),现改为绘制时按当前主题取色。
- 占星轮在骰子页等嵌入场景下的盘底色也随主题切换(此前只有占星主页会跟)。
- 三维天球 / 主限天球 / 天文馆保持夜空底色不随界面主题(天文语义);风水画布只在户型图之上作画,墨色按图片对比度定。

## 排盘设置 · 新命盘的缺省口径

- **新命盘的缺省 = 上次亲手设的值**:黄道 / 恒星岁差 / 宫制、时间算法、八字长生与神煞查法、宿盘宿法、印占的各项选项、主限法方法 / 时间钥匙 / 投影等口径,在你亲手改过之后,新建命盘时缺省沿用;载入已有命盘一律按该命盘自己存的口径,记录里没有的键回出厂值。
- 全局设置新增「时间算法(新命盘的缺省)」。
- 印占载入记录 / 新建命盘时,记录里未存的选项回出厂值,不再沿用上一张盘的设置。
- 未改过任何设置时,请求、快照与存档逐字节不变。

## 排盘设置保留机制的遗留修正

- 七政「报时星 / 罗计取法 / 月孛取法 / 身宫法」首开补空:只作用于七政页自己,不再播给择日内嵌的七政实例;载入了记录的盘不再被补空值覆盖(其余既有三键同样处理)。
- 铁板神数「大运步数」限整数输入。
- 遁甲程序同步性别的改动只作用于当次,不写入保留的设置。
- 地占后端独有的流派档在起盘前也显示中文名。

## 安装器与更新链

- **同版本号重装**:安装器在版本号相同时再比对运行时的内容身份(部件锁),同版本重新打包的安装包也能真正落地(此前只比版本串,同版本重装会保留旧运行时)。
- **发布顺序**:新版本先以草稿建立,运行时与部件先上线、安装包其次、更新清单最后再转正,消除「更新检查已拿到新版本号、部件却还下不到」的窗口;部件复用基线改为取上一版正式发布的清单(此前基线取不到,每版都全量重传)。
- 更新检查与增量下载对用户侧不变:壳按本机部件摘要与线上清单比对,只下载变化的部件。
