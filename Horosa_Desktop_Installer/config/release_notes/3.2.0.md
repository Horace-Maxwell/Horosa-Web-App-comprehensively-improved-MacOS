# v3.2.0

## 名人星盘数据库
- 新增「工具 · 数据库」页:内置高可信名人出生数据与星盘目录(Rodden A/AA 级),全程离线、秒级检索。
- 关键词 / 星座 / 性别 / 出生年 / 评级 / 分类多维筛选与排序;详情页含黄道星盘轮(日/月/上升精确落位)、生平事件、关系与分类标签,并可直达来源页与 Wikipedia。
- **一键加入命盘管理**:任选名人即可导入本地命盘库,之后在占星 / 八字 / 紫微等任意技法页直接排盘。
- 页面主题跟随软件明暗切换、中英双语;成熟分页(编号跳页、每页 24 / 48 / 96)。

## 数据来源与合规
- 出生 / 事件数据来自 Astro-Databank / Astrodienst AG,依其版权条款仅供非商业研究使用,保留 Rodden 评级并附回源链接;传记摘要来自 Wikipedia(CC BY-SA 4.0),均附署名与原文链接。

## 性能
- 数据库页按需加载,不影响软件启动与其它页面的响应速度。
- 运行时随版本号同步为 3.2.0-runtime1。
