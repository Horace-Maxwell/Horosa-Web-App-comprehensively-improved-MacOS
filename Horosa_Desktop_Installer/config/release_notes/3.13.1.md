# Horosa 星阙 v3.13.1

本版以**星运新增四种推运图类技法与全模块版式统一**为主,另有一轮全站选项复审:逐个技法核对「改了设置结果真跟着变」,把查出来的不生效设置、口径不一致与算错的地方一并修好;新增几项古典口径设置(日出 / 日没口径、天医口径、龙盘宫位口径);AI 分析新增「决策层(实验)」设置卡(缺省关)。**会改变已有盘结果的地方,各节里都标了「结果会变」。**

---

## 星运

**新增四种推运图类技法**(各自一个子页,AI 挂载、导出与帮助手册全链可用)
- **演进推运(Néroman)**:对数时标推进(出生时每年约走 364°、越往后越慢),列出演进天顶(Fatum)/ 演进上升(Sensitif)走过四轴的年龄。
- **Bezza 推运图**:真太阳弧 × 世俗时位推进,福点 / 精神点在世俗时位上取;列世俗相位、黄道相位、子午 / 地平映点四类接触。
- **周日小限(Jay)**:天球每年转一宫、十二年一周,诸星保持本命世俗位置随之转动;右栏本命 / 小限对照。
- **双黄道(Michon)**:回归黄道与恒星黄道叠合,按两座守护星的本命距角归入五族,列出 66 组互动。
- 前三种同时给出完整推运盘(本命内圈 + 推运外圈)。

**全模块版式统一**
- 19 个带盘页统一为「左侧整列大盘 + 右栏固定头(时间 · 设置)+ 表格区」:各页盘面同样大小,切页签盘不再忽大忽小;右栏顶部的时间与设置不随表格滚动;多张表按内容公平分配高度,放得下不出滚动条。
- 右栏时间改用与左栏同款的紧凑时间块;年 / 月 / 日 / 时 / 分 / 秒可**按住拖动调整**,松手补算一次。
- 年 / 月加减先落到 1 号再夹回当月天数:此前 31 号加一个月会跳过下个月(10 月 31 日加一月到了 12 月)。
- 改容许度、南北交逆移等即时重算(去掉「提交」按钮);返照 / 流年的「经纬度选择」与「按此地点重算」并排;返照 / 流年盘下的视图切换改为「显示」下拉。
- 太阳弧 / 返照 / 流年 / 小限 / 行星弧的相位统一为同一张相位表(行星弧此前相位表从未画出)。
- 不带盘的页面(星历 / 回归轴 / 法达 / 三分主星 / 数字相位 / 月相推运 / 多重回归)统一标题卡,去掉手动「刷新 / 生成」按钮。
- 切换明暗主题后当前页立即全部换色;日期弹层、页签焦点、分页器与层级色统一为金色。

**修正**
- 会话里改了「行运相位容许度」后,已经打开过的太阳弧 / 返照 / 小限 / 流年 / 行星弧 / 波斯向运等页此前仍用旧值;现在页内值未被亲手改过的会跟着换并重算。
- 太阳返照 / 月亮返照的「内外盘」只在对比盘视图里起作用,其它视图下置灰并说明。
- 星历入座行此前显示「- 30.00°」,改为正确的入座度数(页面与 AI 导出同源)。
- 产前朔望补「朔望盘位置」主卡;双黄道环与行星年龄跟随明暗主题。

## 占星

- **爱欲点(Pars Eros)昼夜公式改正 —— 结果会变**:昼盘为上升 + 金星 − 精神点、夜盘反之(此前昼盘误用了夜式)。
- **半圆上升时度 —— 结果会变**:按定义取巨蟹至射手六座上升时度之和 = 15 × 最长昼(七带依次 195 / 202.5 / 210 / 217.5 / 225 / 232.5 / 240),修正旧算式的错位。
- **新设置「日出 / 日没口径」**(星盘设置):日心 · 不计折射(缺省,与以往相同)/ 日面上缘 · 含大气折射(中纬约早升晚落 5 分钟)。作用于星盘「信息」页的日出 / 日没时刻、七政四余的日出安命,以及行星时「日出起算」制式的报时星。
- **日出 / 日没求解精度**由 1–2.5 分钟提高到 1 秒内 —— 结果会变(七政日出安命、报时星、印度占星 Panchanga 日出同受益)。
- **龙盘「宫位口径」**(右栏顶部):整宫(随龙盘上升,缺省)/ 本命宫头平移(保留分宫制,每颗星落宫与本命一致、只换星座);AI 快照写明所用口径。
- **埃及数字占**:名字里带音调 / 气息符的希腊字母(输入法打出的 έ 等)此前整字母被跳过,现先去符号再求值;补 digamma / 古 koppa。
- **合盘分数 —— 结果会变**:跨盘相位容许度统一为 1°,误差按容许度衰减(正好成相满分、误差 0.5° 剩一半、0.8° 及以上剩两成);同一对星从两个方向看只计一次,顺畅 / 张力与相位清单同样不重复。
- **卜卦盘 / 择日 · 燃烧之路**:各处判定收成同一个函数,一律「含起不含止」(与后端排盘、天星择日扫描同口径);失物「能否找回」与月亮报告随所选边界变体。

## AI 分析

- **新增「决策层(实验)」设置卡**(进阶页):可选接入 TypeSafe System One,把一部分小判断(该不该拦、像不像软件求助、资料片段相不相关等)交给专门做类型化判断的模型,回答仍由你的聊天模型生成。**缺省关,关着时与以往完全相同、不发任何请求**;开启时有知情提示,每个接入点各有分开关(关 / 用 / 影子),且须先在你的模型号上通过校准才会生效;只发最小必要字段,不发密钥与出生资料,任何失败或低置信度都回到原路径。
- 接口档案表单:top_k / top_p / repeat_penalty 等设为 0 后再打开,此前显示成预设值、再存即被覆盖。
- 模型下拉的空态提示按情况区分(没配接口时不再提示去关「仅视觉」)。
- 回答里紧挨着的两段加粗合成一段(此前偶尔出现四个星号连写)。
