# v3.6.1

本版是 v3.6.0 之后的修复与打磨版：以「点了没反应的开关」为主线做了一轮系统排查，修掉四处真失效；同时把窄栏下被省略号截断的文字全面治理干净。

- 死开关排查(本版核心):对左栏、右栏、设置弹层里的选项逐个实点并比对盘面与判读文本的实际变化,修掉四处「能点、状态也变、结果却纹丝不动」的真失效:
  - **紫微·显示杂曜 / 显示十二神**:两个开关此前点了盘面完全不动。它们是纯显示层设置、不进排盘请求,原先靠「重传同一份时间字段」求重绘,参数逐字节相等必被去重挡下;即便强制重渲染,盘面的重绘签名也只比对组件参数、看不见这两个从本地存储读的开关,于是直接判定「输入未变」而跳过整盘重建。现改为显示层独立广播 + 版本号入签名,与排盘请求彻底解耦。
  - **八字·神煞「月令系 / 日柱系」**:两个分组开关在任何盘、任何数据下都移除不了任何东西——四个分组原本一把「或」判定,而全表 49 味神煞没有一味是「仅月令系」或「仅日柱系」,只要吉神或凶煞还开着就永远救活。同一缺陷的另一面:关掉「吉神」时那 8 味「吉+月令」也会被月令系救活而不消失。现按「性质(吉/凶) × 来源(月令/日柱)」两个正交维度判定:维度内取或、维度间取与。
  - **显示星体·汉堡八虚星与七政命度点**:在西洋盘族的星体面板里勾选它们恒无反应——这九个点位的绘制只存在于量化盘与七政盘。现置灰并注明去哪里查看,不再让人反复点一个不会有反应的开关。
  - **八字·流派标记**:在「传统综合 / 纳音古法」下本就不出单派喜忌徽标,开关点了无变化。现按当前流派置灰并说明换单派后生效。

- 窄栏文字截断全面治理:
  - **左栏宽度回归修复**:卜卦 / 择日 / 世俗三页的左栏此前被辅盘族的通用规则压窄了约 64px,导致复选框标签被截成「问题真…」、三档「时空中点」挤成两行。现由三页各自的规则独占裁定宽度。
  - **下拉收起态短名**:窄栏里的下拉选项普遍带括号补充(如「启发式（现行）」「传统（4父/10母）」),收起后被截得看不出选的是什么。现收起态只显示主名,展开面板与悬停提示仍是完整口径——卜卦判读 13 项、择日流派口径 13 项、世俗四项全部接入。
  - **辅盘十二个子盘逐个实测零截断**:量化盘 / 十三分盘 / 十二分盘 / 占星地图 / 重置盘 / 调波盘 / 龙盘 / 骰子 / 卜卦盘 / 择日盘 / 世俗盘 / 巴比伦,左右栏均无被裁切的文字。世俗盘四个下拉改为一行两个以节省纵向空间;择日「表格速查」按钮标签精简;十二 / 十三分盘的「宫位与黄道」按钮不再被挤掉尾字。
  - 停用项的长解释从行内文字改为悬停提示(窄栏必截,且说明文字本就该进帮助手册)。

- 数算三修与 AI 修复(承 v3.6.0 后续):
  - **河洛理数**:立春前出生者的流年干支此前整体错位一年(按公历年而非交节时刻定干支),已按立春界根修;流年表的干支行同时加显对应公历年与立春时刻。
  - **邵子参评数**:左栏「性别」选择后无反应的死开关已接线;大运排法补齐三档并按考据默认切换,起运岁按单月逆数、双月顺数推算。
  - **AI 分析**:OpenAI 新代模型(gpt-5.x 及 o 系)只认 `max_completion_tokens`,旧代与部分第三方模型只认 `max_tokens`,此前混用导致新代模型请求恒被拒。现按模型代际自动归一,并保留响应端自愈层。

- 启动观感:应用启动画面与外壳启动页统一为同一套视觉(品牌墨绿、暗色渐变、星点),启动过程中不再出现「闪一下换成白色卡片」的跳变。

- 界面细节:卜卦盘界限环在单色主题下不再呈灰带(界主同色时退回星座色区分);右栏判读条的标签列放宽,最长项不再压到数值上。
