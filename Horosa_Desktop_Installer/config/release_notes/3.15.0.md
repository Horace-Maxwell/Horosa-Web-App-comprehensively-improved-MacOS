# Horosa 星阙 v3.15.0

本版:奇门遁甲补齐一组附加层(暗干第六法、寄干与天禽、翻宫 / 转宫推演、十二建星)并更正两处排盘;所有随机起卦 / 抽牌 / 掷骰换成真随机;全站键盘可达(Tab / 回车 / 空格 / Esc),按钮、基础控件、提示条与弹窗统一成一套;首屏体积减半;外部智能体接口新增 29 件工具,无头常驻服务可以跑定时任务;批量验证做到跨平台逐字一致,并新增命题验证 `./horosa verify`。另有一批口径更正,条目里标了「结果会变」。

## 界面与流畅度

- **键盘 Tab 能走到按钮**:此前系统没开「键盘导航」时,按 Tab 只在文本框、下拉上停,「起盘」「确定」这类主按钮用键盘到不了;现在主窗口、偏好设置与诊断窗口里,Tab 依次走到按钮、链接、复选框。侧栏分节标题整行只停一次。
- **原来只能用鼠标点的块可以用键盘操作**:全站两百多处可点的卡片 / 列表项 / 单元格可以 Tab 聚焦、按回车或空格触发,聚焦时有统一的金色焦点环;页面原有的空格 / 数字键快捷键照常。竖排页签每个页签只停一次。
- **Esc**:黄历日卡浮窗可以按 Esc 关;弹层叠在弹窗上面时,Esc 只关最上面一层,不再连下面的弹窗一起关。
- **系统提示条统一**:服务中断 / 警告、多开实例、本地存储这几条横幅此前各是一套样式、各自固定在窗口上会互相压住;现在同一外观(随主题,左侧色条区分轻重,按钮可用键盘),按轻重排成一列,不再盖住弹窗。
- **按钮与基础控件全站一套**:复选框、单选、滑块、数字框、加载圈、空状态统一成随主题的同一套外观;各页按钮同一档圆角与高度,两个字的按钮中间不再自动插空格;主限天球的缩放滑块不再是蓝色。
- **加载 / 出错 / 空三种状态**:推运类页面和辅盘的龙盘 / 调波 / 重置三页,加载中、出错、没有内容各有统一的提示;请求失败可以点重试。
- **弹窗与抽屉**:正文实底;宽度全站统一封顶,不会超出窗口。
- **竖排页签条不再被推出窗口**:工作区横向滚动时(放大档尤其明显),竖排页签条此前会跟着滚到窗口外;现在钉在可见边上。
- **首屏更轻**:首屏要加载的脚本从 14.4 MB 降到 6.3 MB —— AI 助手、操作手册正文、Word 导出库等改成用到时再加载;功能不变。
- **盘面文字**:金口诀盘、七政方盘的地支与盘角信息字,星盘盘角的出生 / 行运信息字,不再描边(此前发粗发糊);七政(坚七政样式)相近几颗星的名字与度数标签沿圈推开,不再互相压字。
- **九家择日工作台统一**:八字 / 紫微 / 六壬 / 奇门 / 太乙 / 三式 / 七政 / 印度 / 黄历择日的交互与版式统一 —— 紫微择日补上「数字框留空」的校验,奇门与三式的展开参数用同一套网格,结果表「盘」列同宽,保存的方案文件名一律「<家名>方案_…」,放大档不再溢出。
- **版面**:星运的主限法盘 / 流年法右上角「行运经度」一行不再越出盘面;小六壬「拜解一览」放大档两字词不再被挤成逐字竖排;地占护盾盘窄格里格头位名与得地角标不再互压;地占十二宫列表窄右栏里宫名不再竖排、长拉丁宫名不再戳出卡片;辅盘龙盘「宫位口径」标签不再竖排。
- 帮助页打开时有加载骨架,鼠标悬停时预先取内容。

## 奇门遁甲与三式合一

- **值符天芮、时干在中五宫时天盘干改为伏吟 —— 结果会变**:这种时辰九星没有动,天盘干应与地盘干逐宫相同;此前九星、八神是伏吟,天盘干却错转了一宫(阳遁转到巽、阴遁转到震),全年约 1.1% 的时辰受影响,右栏格局、旺衰、十干克应也跟着按错的天盘算。奇门帮助补了「时干在中五宫」一条。
- **值符是天禽时由寄宫之星代它领盘 —— 结果会变**:「中宫寄宫」选了非缺省档时,九星层和值符名此前恒按坤宫之星排,天盘干却按寄宫之星排,两层对不上(各档 7%–12% 的时辰);现在九星、值符名、天盘干用同一颗星。缺省「恒寄坤」结果不变;值使借哪个门仍由「值使取法」单独决定;星层取飞盘时不代。
- **「中宫寄宫」新增「阳遁寄坤 · 阴遁寄艮」一档,「值使取法」新增配套的「阳遁死门 · 阴遁生门」**:随遁寄宫古籍两说并存,两个方向都给;缺省仍是恒寄坤二,原有各档不变。奇门页、三式合一、AI 挂载设置、择日都能选到。
- **暗干新增第六种起法「时干加值使 · 按天盘干序转」**:时干加在值使门落宫,其余各宫按本局天盘干在八宫的实际排列整圈转。默认关。
- **寄干与天禽落宫可显示**:中五宫的干在地盘寄到寄宫、在天盘随从寄宫出发的那颗星落宫,天禽跟同一颗星;飞盘不寄。默认关。
- **新增翻宫 / 转宫推演显示**(只是显示,不改排盘):翻宫上翻 / 下翻各三步,伏吟时注明翻宫无效;转宫:空亡转对冲、大伏吟转先天八卦位;用神宫可选;左栏有图例。默认关。
- **新增十二建星**:奇门页九宫外可开一圈十二建星外环(左栏与盘下图例行末的按钮一键开关,日值金底标「日」),右栏有日值 / 时值卡,AI 快照多一行;三式合一右栏有十二建星卡,盘开着时外圈每个地支旁挂建星。日值按「逢节重复」(交节当天整天算新月建),与黄历同一口径。
- **盘格附注改「上挂下注」**:奇门大盘里暗干挂在门上、推演标记在门下、天盘寄干在天盘干上、地盘寄干在地盘干下、天禽在九星下,位置固定,与主字留出安全距离;放不下时先换行、再缩字、再简写,最后才收进悬停提示。三式合一盘格内只放寄干与天禽,暗干与推演标记移到每宫旁边的空格,不再被右上角八神盖住。没有附注时主字位置与此前逐像素相同。
- **转盘中宫格显示排入中五宫的暗干**:「时干加值使 · 飞布」「满盘旋转飞」两种起法总会把一个暗干排进中五宫,此前盘上看不到;现在大字下方多一行「暗 X」。

## 起卦、抽牌与掷骰

- **一律真随机**:随机数只取操作系统的随机源(Mac 上由芯片的硬件随机数发生器供给),取不到就报错、不留退路。此前六爻掷钱 / 蓍草、骰子、五兆掷钱、地占 / 五兆 / 荆诀 / 太玄的种子、皇极随机历史年、小成图大衍 / 摇钱、塔罗洗牌、灵棋掷棋用的是各种伪随机。手动整数种子、时间起卦、塔罗生辰种子、报数起卦是确定性起法,照旧;旧卦例重开结果逐字不变。帮助里写明了随机从哪来、哪几档是确定性起法。
- **塔罗洗牌真正洗得开**:此前洗牌只用种子的前 32 位,七十八张牌的绝大多数排法出不来;现在每一步独立取随机数。
- **塔罗「种子来源」缺省改为「随机」 —— 结果会变**:「出生信息」档的种子只由姓名、时间、经纬度决定,和所问的事、抽牌时刻无关;现在下拉里「随机」排第一,「出生信息」留作自己选的确定性档。已经存过设置的不受影响。
- **种子的显示与输入**:随机起的卦,种子写成「真随机 fac33ab4…」(只留开头 8 位,全文在悬停提示和种子框里),重开卦例按这份记录原样回放;三个数字种子框改成文本框,既能填整数也能粘贴真随机记录。
- **去掉两处取余造成的不均匀**:骰子、数字起卦附加随机数此前各点数概率略有偏差,现在等概率。
- **交节当天、交节时刻之前起的皇极 / 五兆 / 神易数 —— 结果会变**:此前交节当日整天都按新月算(2027-02-04 03:15 写成丁未年壬寅月,同一份快照里节气却还是大寒);现在按钟面时刻取年月柱。太乙与五兆在立春前夜晚子时也不再提前进新年;神易数的起课分钟进计算。黄历按日记柱是历书惯例,不改。

## 占星与星运

- **赤纬平行表按「两两都在 1° 内」成组 —— 结果会变**:此前链式并组(甲乙、乙丙各差不到 1° 就三者同组,甲丙可能差近 2°),同一对星既单列又并在大组里,结果还随遍历顺序变;现在每组内任意两星都在 1° 内,相邻两组可以共用一颗星。反平行表、各点赤纬不变。
- **星历表里行星「留」的时刻 —— 结果会变**:此前同一个天象在不同命例里秒数不一样,且比黄经真正的极值点晚(海王星约 65 秒);现在按位置求黄经极值,时刻取到分钟。
- **并列行的先后固定 —— 结果会变(只是次序)**:世俗相位里数值并列的行、主限法与推运图族各表里弧值并列的行(多是北交 / 南交、福点那一对)、周日小限落宫、年龄点一周后回到上升的那次穿越、龙头盘恰在整度上的点,此前先后取决于浮点末位,不同机器可能不同;现在差不到十亿分之一的两个值当相等,按固定规则排。行的内容不变。主限法缺省的 Alcabitius + Ptolemy 弧值逐字不变。
- **推运图天顶时位**:恰在 24 点的写成 0 点(同一位置此前有的机器写 24.000、有的写 0.000)。
- **「主限法」和「主限法盘」给 AI 的资料不再串**:此前只存了主限法表格时,挂载或导出「主限法盘」拿到的是表格正文;现在各取各的。
- 调波盘 / 龙盘 / 重置盘给 AI 的专属段,星、点、星座由英文代号改成中文名。
- **高纬度(≥ 63°)起盘从数秒降到零点零几秒**,结果逐例不变:此前地理纬度 ≥ 66° 的本命盘要 3–10 秒,原因是给行星标「晨星初现 / 昏星初没」时高纬度常连续几个月看不见、逐日搜索很慢;现在先排除再搜,并按进程缓存。偕日升搜不到时不再连带丢掉偕日没。

## 中式术数

- **皇极经世:公历年初、还在农历上一年里的日子不再整盘错一年 —— 结果会变**:此前这类日子整盘按上一年同月同日算(1990-01-01 出成 1989-01-01 的四柱与各卦);现在会运世一律按农历年,四柱 / 节气 / 显示日期按原公历日期。
- **宿占宫宿表改按赤经分宫 —— 结果会变**:赤经每 30° 一宫、从命宫段起数,星曜按赤经落宫;非整宫制下不再出现地支重复 / 缺位。
- **邵子数的元会运世按真实出生年重算 —— 结果会变**。
- **七政四余在极圈以内能起盘**:此前北纬 67° 以上整盘起不出来。
- **八字给 AI 的资料和导出多一段「卦释」**:胎元 + 四柱逐行的本卦 / 互卦 / 旁通。自定义过八字导出段的会一次性并入这一段(取消过的段不会复活)。
- 七政给 AI 的「年限」段,当前大限写成「财帛宫(未) · 限主太阴 · 20–44 岁(2010–2034)」这样的句子(此前是一串字段名);铁板「大运」的号码标明是条文号(此前「10岁:1945」读起来像年份);算命学三柱注明日柱按 0 点换日;演禽格局正文不再带出查表字段名。

## 印度占星与量化盘

- **印占行运(Gochara)的「遮蔽」标注 —— 结果会变**:此前凶位一律标「Vedha 遮」;现在只在确实被遮时才标,并写明是哪颗曜遮的;罗睺 / 计都只给 SAV。
- **量化盘并列与边界固定 —— 结果会变(只是次序与边界归属)**:中点与中点相位(正对的两点取黄经小的那个中点)、行星图 / 映点 / 和点 / 差距 / 指针读数 / 中点树 / 太阳弧表、90° 盘折叠位、六宫框落宫,不再随浮点末位变;印占 Mūla 大运组内并列项同此。
- **量化盘的时间层可以交给 AI**:挂载设置新增行运时刻、差值表开关与口径,给了行运时刻就多出「行运接触」段;给了起止日期就出「图形星历」段(行运折叠线与本命参考线的交点日,最长 366 天)。不填与此前相同。差值表改为到期的排前、同文去重、南北交不列(此前前几行全是 0 岁的平凡行)。

## AI 分析

- **空白状态重做**:标题换成随时辰变的问候;输入框成为一体 —— 顶行是「案例」「模型」入口(选了案例多一个「挂载」),工具排只留添加图片 / 挂载 / 模版,次要动作收进「更多」;还没接入模型时出三张引导卡,接好即消失。
- **定时任务到点会挂上任务里选的技法**:此前到点只挂整盘。
- **挂载设置新增一批可调项**(不填都与此前相同):主限法相位集;星盘「盘面细节」按表取全表;星历区间、回归轴起年与年数、多重回归星体与回数、七政流年时刻;卜卦盘 / 择日盘的宫制、黄道、岁差制;择日盘本命合参与危象日;六壬 / 金口诀问测人出生与性别;奇门「相关人员」;三式合一外圈分宫与上升取法;世俗盘全部十类盘种的参数;奇门附加层与十二建星。
- **三式合一给 AI 的资料补两段**:后台重算时此前缺「紫微四化」段,也没有「八宫逐宫」段。
- 金口诀重算不再丢掉存档里的行年;玄空快照不再出一行空的「逐宫:」;任务中心的提案显示补齐动词与内容预览。
- 资料库导入超过 50 MB 的文件时,此前确认框弹不出、这一批导入无声中断,已修复。
- **导出 PDF**:编号列表的编号照原文写(此前一条编号项后面跟着说明段落时,每一条都印成「1.」;Word 与 TXT 一直是对的);内嵌字体没有的繁体 / 异体字(「尅」「隂」「齡」一类,约 1500 个)改用同一个字的通行写法,不再印成方框;「✗」不再印成方框。

- **终端**:`./horosa setup --local-only` 不装、不用 Homebrew,缺的运行时下载到仓库内;`./horosa config calls-per-minute` / `writes-per-hour` 人工调限流额度(调高要本人确认);需要本人确认的子命令没得到确认时退出码为 6;`call --data` 只打印结构化结果一行。
- **出错信息与协议**:失败结果带「重试有没有用 / 下一步怎么办 / 限流要等多久」;参数写错报一句中文(字段路径 + 原因),枚举写错提示相近的值;工具被开关关着时回「工具已关闭」并写明该开哪个开关;写入类工具可带幂等键,重复调用不重复写;客户端断开会取消在途调用;REST 错误码与状态码整理(404 / 422 / 429 / 504;`error.code` 现在一律是字符串,原来的数字码在 `error.rpcCode`),OpenAPI 文档补齐。
- **调用时限跟工具走**:客户端没给时限时,按这件工具自己声明的时长等(逐时择优、校时扫描、多模型对比这类长任务声明 3–15 分钟),不再一律 2 分钟就中止;可指定的时限上限由 10 分钟放到 30 分钟(MCP `_meta.timeoutMs`、REST `X-Horosa-Timeout-Ms`、终端 `--timeout` 同步)。
- **修掉的问题**:无头 HTTP 此前随便编一个会话头就能拿到一份新的限流额度,现在只认本服务自己发的会话;外部写入每小时上限此前按会话分,现在是所有外部会话合计;工具目录超过 64 件后排在末尾的会被截掉,上限提到 128;七政在无头模式下的流年误用出生年;报数起卦的数字项填了非数字 / 超范围时不再被悄悄换掉,当场判为坏值;AI 提议的新模版 / 技能包 / 个人口径,审阅时此前只显示前 400 字,现在显示全文并写明新旧各多少字(无头终端在确认前先把要写入的内容打出来);按工具名禁用了起盘工具后,「存成文件」不再能拿到同一份正文;回收站列表可以翻页;农历月历的月份写成 13 月时报参数错。

## 批量验证与命题验证

- **`./horosa batch --now "…" [--tz …]`**:把「此刻」和时区钉住,同一批命例重跑逐字相同。此前不少技法的正文会取当前时刻(推运类的目标时刻、返照 / 流年的今年、当前大运标记等),隔天重跑就不一样。不给这个参数 = 用真实的当前时刻。
- **跨平台逐字一致**:macOS arm64 与 Linux arm64 对拍,命盘 60 例 × 66 技法 3960 格、起课时间 60 例 × 22 技法 1320 格逐字相同;与 Linux x86_64 只剩约 0.5% 的格在秒位或末位小数上差 1(处理器浮点差异,不影响判定)。办法是并列与边界不再看浮点末位(见上面各节「结果会变」的并列条目)。
- **新增命题验证 `./horosa verify`**(运行包里是 `horosa-verify`):用一份命题文件写明命例来源、钉住的时刻、判据、命题与门槛;支持「凡…则…」、关联(费希尔精确检验)、比例(二项精确检验),带多重比较校正,判据三值(技法没起出来 = 不知道;正文超长被截断的格里没找到的内容也记不知道,可在命题里写 `sections` 只取要用的段),校正的条数按命题总数算,全程精确分数运算。起盘不读本机存的技法设置,口径只认命题文件里写明的。产出分层凭据,可用 `--check` 在另一台机器上重跑复核:判定层必须逐项相同,正文差异另报并指出是哪个技法,`--strict` 连正文也要求相同。报告先列每个判据的 是 / 否 / 不知道 计数。
- **`--kind timepoint`**:批量可以按起课时间起盘(六壬 / 奇门 / 太乙 / 金口诀 / 三式合一 / 卜卦盘 / 世俗盘 / 黄历 / 节气等 22 个技法),命题验证同样支持。
- **取数不全的结果不采用**:起盘回报成功、但途中有发给计算服务的请求最终失败的格,单独记为 `E_BACKEND_PARTIAL`,不算数(此前有的技法取数失败照常出正文、只是少一层,机器忙时同一例结果会悄悄不同)。
- **Linux**:此前凡经排盘服务的技法在 Linux 上全部起不出来(精简镜像里没有 `ps`,起停脚本把活着的服务判成退出;星历路径在 Linux 上每个线程各一份,工作线程没设好),已修复。运行包与容器镜像瘦身:Linux 的 Python 依赖清单去掉排盘计算不调用的界面框架,运行包 343 → 295 MB,容器镜像约 2.4 → 1.5 GB(运行包也不再带上本机运行留下的结果缓存与日志);容器入口第一个参数写 `verify` 即进命题验证。Windows 经 WSL2 或 Docker 使用。
- `--timeout` 最多可到 3600 秒;汇总里记批量种类与运行环境。

## 引擎与性能

- 太乙 / 三式择日扫描提速约 30 倍(只排条件涉及的那几家)。
- 本机前端与后端之间请求加密用的钥匙改取系统随机源。
