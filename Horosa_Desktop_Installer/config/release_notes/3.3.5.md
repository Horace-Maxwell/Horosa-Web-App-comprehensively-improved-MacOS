# v3.3.5
- AI 挂载 / 导出「纳入内容」所见即所得修复:此前多处「勾了没纳入 / 取消不掉 / 清空按钮点了没反应」的问题一次性根治——「清空」现在真的清空、清空后勾选某段就只纳入该段；三式合一等技法此前无法取消的固定段现在可自由取消；事盘/命盘的整盘内容也一并按「纳入内容」设置裁剪；设置面显示什么，AI 导出与挂载就吃什么，完全一致。
- AI 段名全面对齐:穷举核对了全部技法「导出设置里的段名」与「实际生成的内容段」——合盘（合成图盘/影响图盘）与节气 3D 盘的盘体此前在自定义分段时可能被误删只剩空标题，现已收进对应盘的整段不再丢失；宿盘「遁甲外盘」不再覆盖真正奇门遁甲的 AI 快照；主限法等技法的空占位段与缺失段全部修正。
- 「星曜后天信息」等导出附加开关现在挂载分析时同样生效，导出与挂载行为完全一致。
- 稳定性与性能:延续既有全域性能优化（冷启动、缓存、连接池、增量更新）与稳定性加固，本版无回归。
- 运行时随版本号同步为 3.3.5-runtime1。
