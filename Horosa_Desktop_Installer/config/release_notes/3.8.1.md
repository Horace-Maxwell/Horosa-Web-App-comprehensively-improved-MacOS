# Horosa 星阙 v3.8.1

本版为西洋占星全站带来「盘面美术」：同一张盘，五种画法随心切换——经典圆盘之外，新增希腊盘、中世纪盘、北印度盘、南印度盘四种方形覆盘。所有占星单盘页面全部支持，选择跨会话保存。

## 盘面美术 · 五档全站可切

- **五种画法**：经典圆盘（默认，与既往完全一致）／希腊盘（九宫格，1 宫恒为左中完整格）／中世纪盘（内切方形+十二三角，1/4/7/10 宫恒居四边正中）／北印度盘（菱形盘，宫位固定、星座随上升转）／南印度盘（星座固定格，宫号随上升转）。
- **方形覆盘的读法**：每格（三角）即一个星座；行星按星座入格、附度分与逆行标记；上升（Asc）与天顶（MC）以红字标注；象限制下各宫头的投影度分也标在对应格内（整宫制宫头恒为 0° 时自动省略）。
- **入口**：左栏「星盘样式」卡改为一行两个下拉——「外环样式」（清简／经典，仅经典圆盘下生效，方形盘时自动置灰）＋「盘面美术」（五档）；「星盘设置」抽屉的盘面显示卡内也新增同源入口。改一处，全站同步。
- **覆盖范围**：本命、合盘（组合盘／比较盘／时空中点盘／马克思盘）、辅盘全家（量化盘行星中点与六宫框、十三分盘、十二分盘、重置盘、调波盘、龙盘、骰子盘）、卜卦盘、择日盘（含天星择日条件预览）、世俗盘、节气盘、法达、小限、产前朔望等全部占星单盘。
- **成文边界**：推运／返照等双轮叠盘恒用经典圆盘（方形盘没有双轮画法）；相位线、卜卦判读叠层、键星聚光、黄道释放高亮等圆盘专属叠加，方形盘下不显示，需要时切回经典圆盘即可；90° 中点盘、图形星历、占星地图等专用画布不参与；印度占星专页保持其北印／南印／东印三档不变。
- **排版细节**：中世纪盘的星座徽章骑在宫头分宫线中点、白底衬框防线穿字，宫号贴近内方形，星体锚在各三角形几何中心；北印度盘（含印度占星专页同步优化）角部三角的星座徽章对齐长边中垂线，度分完整显示不压边；全部星座符号统一定宽，窄字形（如狮子座）不再与度数叠字。

## 修复

- **辅盘各页选了盘面样式没反应**：十三分盘、十二分盘、量化盘等辅盘页面此前存在「设置改了、盘不跟着变」的断链，已逐页接通并以自动化总锁看住（新增页面漏接会直接在测试中报红）。
- **量化盘不跟随全局设置**：在「星盘设置」里改盘面美术后，量化盘行星中点／六宫框现已即时同步。
- **从方形盘切回经典圆盘后盘面空白**：切换后圆盘不重画的问题已根治，任意来回切换均即时重绘。
- **盘面隐藏期间的补画机制**在切换过盘面美术后失灵的问题已修复（隐藏分页里的盘在切回时保证是最新数据）。
