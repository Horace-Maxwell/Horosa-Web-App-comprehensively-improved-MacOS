# Horosa 星阙 v3.13.2

本版修复一个启动问题:**软件内更新后的第一次启动,首页盘可能报「排盘错误」并提示连不上排盘引擎,重启一次才正常。**

---

## 修复

- **更新后首次启动的排盘错误**:更新会换掉整套运行环境,macOS 对新装入的原生库在第一次加载时要做一次安全检查,所以那一次排盘引擎会比后端晚起几秒。此前界面只确认后端就开始排盘,请求经后端转给还没起来的引擎,于是报错。现在界面会等后端与排盘引擎都就绪后才发排盘请求;平时启动不受影响(每个服务确认一次后不再重复检查),引擎确实起不来时仍按原有时限给出提示,不会一直等下去。

## 说明

- 已经装好 v3.13.1 的用户:这次更新后的第一次启动就会用上本修复。
- 增量更新只下载变化的部件。
