# Horosa 星阙 v3.9.0

本版是一次**内容与稳定性的双重大版本**：新增一门完整技法「灵棋经」，六个既有板块依古籍全量补齐（策天飞星／塔罗／五兆／小成图／风水／天文地占），帮助手册全面改版为两层页签、每门技法独立成页；并根治了一个影响面覆盖全部占卜技法的存档缺陷——**保存后再次读取同一条记录，出来的卦可能不是当初那一卦**。

---

## 新增技法 · 灵棋经

「卜 · 其他」新增第十五门子技法。

- **一掷成卦**：十二枚棋子分上（君·天）／中（臣·人）／下（民·地）三层，每层四枚、正覆各计，一掷成卦；也可开「手动摆棋」逐枚点翻，或直接录入三层之数。
- **全书数据化**：一百二十五卦（一百二十四正卦 + 纯阴镘）的卦名、棋数、象名、属性、繇辞、四家注、课断、断诗（含四十处第二首「又曰」）悉依四库本全文录入，原书缺注之处如实留白、不代补。
- **简繁双轨**：正文默认简体，可一键切回四库原文；卦名带、注解、课断、断诗全部随档切换。
- **可复现**：种子来源三档（随机／时间种子／手动种子），同种子恒得同一卦；「锁定复现」一键把当前卦的种子固定下来。起出即冻结——此后改时间地点、改显示口径都只重排判读，绝不悄悄替你换一卦（古法「一时掷之，不可再掷」）。
- **右栏七页**：概览（含三才数性、耦敌、阴阳多寡与占时四柱）／繇辞／诸家注（四家分卡）／课断／断诗／仪轨（卷首造棋法、占仪、祭仪全文）／帮助。六戊日按古法给出提示，不阻断起卦。

## 🔴 重要修复 · 存档保真

**症状**：保存一次占卜结果后，再次从记录列表载入同一条记录，出来的卦可能不是保存时那一卦（例如中途重新起过卦，再载入就停在新卦上）。

**影响面**：全部二十一门有存档功能的技法，无一例外。

**已根治**，并同时修复同一批的四类相关问题：
- 部分技法（塔罗、天文地占等）在已经停留在该技法页面时载入存档，**载档静默不生效**；
- 六处存档入口漏带「日界点／晚子时／时间算法／性别」等口径，载回来会被当前全局设置覆盖，导致日柱时柱算错；
- 三门技法在还原后又被后台重新取盘覆盖；
- 若干选项存了却没读回（起卦法、种子档位、起支法与日干支档位等），以及载档后左栏仍显示先前草稿时地。

现在：**保存后无论载入多少次，时间、地点、全部选项与卦相都逐字复现当初那一次**。并新增跨技法自动闸门，此后任何技法漏存或漏读一项都会被自动拦下。

## 其他修复

- 子页签跨主页签往返被打回首档：在「其他」「辅盘」「传统」「择日」四组里，停在某个子技法后切走再切回，现在会回到你原先那一页而不是第一页。
- 塔罗：判读口径六项改为一行两个的下拉（原先横排控件占去左栏近半高度）；单卡详情弹窗在浅色主题下正文看不清的问题已根治；无专属细则的牌阵不再显示空卡片。
- 五兆：右栏移除一个与占断无关的资料页签。
- 个人牌义与日课日志改走带配额自愈的存储通道，避免存储写满时报错。

### 演禽 · 策天飞星 · 盘心
- **四柱不再是空的**：这两门的盘心四柱此前一直显示占位符「—」（演禽四格全空、策天只有年柱），现按起盘时刻完整排出年月日时四柱。
- **盘心四项各归各名**：这两门借用的是紫微的盘面版式而非紫微的术语，此前把演禽的「胎星」标成「子斗」、「三元」标成「斗君」，把策天的「命宫」标成「命主」。现分别显示为命星／身星／胎星／三元与命宫／身宫／紫微／时辰。
- **盘心不再被按钮压住**：移除盖在盘心上的「命盘信息」按钮（它挡住四柱与命星行；这些信息右栏概览本就一直在显示）。
- 新增左栏「中宫内容」三档（简洁／四柱要素／全量信息），两门各记各的选择，与紫微的同名设置互不影响。
- 盘心文字过长时自动收敛，不再冲出盘心压到相邻宫的星名上。

### 风水
- **加粗终于正常显示**：各派条文里用于标重点的记号此前被原样画成星号（如「\*\*绝不能勉强理气上的旺向\*\*」），现正确显示为加粗。
- 罗盘用法新增首条建议：**不必另购实体罗盘**——可用卫星地图沿建筑外墙拉线读出真方位角，填进左栏「真方位角」并选所在城市，本页即自动换算坐向、三针读数与分金；钢混高层室内磁干扰大，卫星地图取向反而更稳。
- 改造化煞：盘面显著放大（此前右侧大片留白），格内煞名不再溢出格子；同一宫的两条煞名改为各占一行，不再被截断丢字。
- 理气各派左栏加宽，长选项不再折成三行（户型图阳宅两法维持原样）。
- 经纬度改为专业记法（119°19′0″E／26°4′0″N），不再显示一长串小数。
