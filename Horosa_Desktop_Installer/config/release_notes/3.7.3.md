# Horosa 星阙 v3.7.3

## 三式合一 / 奇门遁甲 / 奇门择日 · 改时间即时出盘

此前在这三处改了时间或选项后，中栏盘面与右栏数据不会跟着变，必须再手动点一次「确定」或「起盘」才更新。现已改为：

- **首次仍须显式起盘**——刚进页面时中栏保持空白，由你点「起盘」决定何时开算，不会因为随手拨了下时间就自动跑一盘。
- **一旦盘已经起出来**，之后改时间（含上一时辰／下一时辰等步进）或改选项，中栏与右栏立即按当前显示的时刻重算，所见即所得。
- **整盘一起跟着走**：此前有一种情况是盘面「看着没动」——中栏表头、奇门盘与太乙盘都换了，唯独**外圈星度（天顶／上升／各曜度数）还停在起盘那一刻**；而在同一个时辰内，奇门局与太乙局本来就不变，于是整盘看上去纹丝不动，非要跨过一次时辰交替才「恢复正常」。这个问题已彻底修复：现在每步都按当前时刻重取星盘，四分钟一档也能看到上升与天顶逐格推移。

奇门择日内嵌的遁甲盘与独立奇门页各自独立，互不串扰。

## 奇门遁甲 / 奇门择日 · 重算时不再整屏变白

重算期间那一大片覆盖全屏的加载遮罩已撤除，改为中栏右上角一枚小小的「重算中」标记。重算时旧盘保持可见、左右栏照常可读可操作，不再被整屏挡住（三式合一上一版已如此，这版轮到遁甲与择日）。

## 六壬盘 · 四角地支排版

三式合一的六壬环里，四个角上的地支贴着边框、看着偏斜的问题已修正：角上的地支不再压到框线，与相邻地支沿对角线对称；宫位数字位置保持不变。

## 奇门择日 · 首次进入不再卡顿

软件启动后第一次点开「择日 → 奇门择日」子页签需要等待、而其它子页签都是瞬间进入的问题已解决：该面板改为在主线程空闲时段预先建好，你点开时已经就绪。进入择日页本身的速度逐字不变，其它部件不受影响。

## 增量更新 · 包体大幅缩小

增量更新在多数情况下会把整整几百 MB 的组件重复下载一遍的问题已修复。未改动的部分（星历数据、Java 运行库、Python 运行时、玄史资料等）现在能被增量更新稳定识别并跳过，687 MB 组件中的 550 MB 在相邻版本间可直接复用。日常小版本更新的下载量因此显著下降。

## 太乙 / 二十八宿 · 六处算法勘误

- **节气距离**：所求节气就在当日或之后时，天数不再凭空多出一整年；全年份域（含公元前与远未来年份）一律适用。
- **宿度表**：虚宿度数、周天总度修正为古法定值，不再与 360 度混用。
- **节气锚点**：霜降与立冬的对应宿次此前互换、夏至与大雪落错宿，均已按等分周天校正；锚点缺失时明确报错，不再静默取到相邻节气。
- **紫微天才 / 天寿落宫**：起宫基准修正，此前这两颗星的落宫会整体偏移。
