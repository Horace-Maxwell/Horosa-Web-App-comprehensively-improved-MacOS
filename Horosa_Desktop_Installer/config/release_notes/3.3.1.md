# v3.3.1
- 全球安装可用性加固:macOS 12.0–12.2(Monterey 早期小版本)界面完全兼容——主导航隐藏项与左栏全宽展开在旧版系统 WebView 同样生效,并补齐一组标准 API 兜底;一台 Mac 多账户共用时,任一账户完成更新/回滚后其他账户可继续正常更新;升级安装时自动请正在运行的旧版本退出,避免新旧版本串跑。
- 启动体验:首次(或更新后)启动显示预计耗时提示,不再被误当卡死;启动异常时界面直接给出诊断日志目录,求助定位一步到位;从压缩包直接双击运行时,提示移入「应用程序」以获得完整自动更新体验。
- 打包链路健壮化:内嵌运行时依赖自包含核验入闸,发行物纯净度随每次打包自动把关。
- 七政四余大幅增强:Moira 式盘面全面重制(动态环布局、四角标注、难仇恩用/度宫山/虚实四柱/星曜双列诸表、庙旺与顺逆留伏迟疾星点动态);百六大限与飞限·小限·月限算法与显示对齐;宿度制黄仪/赤仪共九档可选;天星择日升级双轮盘(真太阳时、磁偏、二十四山座山指北、罗盘宿/西占带);「出乾入巽」等格局用字校正;内置操作手册与资料速查全面补写。
- 奇门遁甲增强:用神「值符/值使」落宫与盘面八神对齐;概览新增「全局格局速览」;命局/事局按日时干分别语义标注;卦后数字改用洛书宫数;「时机」版块布局优化;内置操作手册。
- 六壬:「信息」卡三列紧凑排布,一屏纵览。
- 全站「快捷功能坞」:各技法底部一键跳转常用功能入口。
- 经纬度选城市或地图点选后,地名自动回填「地点」并随命盘保存(全技法通用)。
- 名人星盘数据库:内置操作手册。
- 运行时随版本号同步为 3.3.1-runtime1。
