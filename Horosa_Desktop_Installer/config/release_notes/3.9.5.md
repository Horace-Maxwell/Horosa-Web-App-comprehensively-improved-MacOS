# Horosa 星阙 v3.9.5

本版是**卜卦盘的一次全面改进**：修通了三条从未真正生效过的判读要素（映点成事、互容、被围），系统性完善完成法与应期算法，新增「问谁的事」转宫人称档与可选的「全证词池＋置信度」裁决算法；同时对择日盘的评分体系做了重标定，让分数回到正常分布。

---

## 卜卦盘 · 判读要素修通（三条「从未触发」的死链）

- **映点成事、互容、被围三条判读路径此前从未真正生效**：读取排盘服务结果的代码与实际数据形状不符，导致这三类征象恒为空。现已全部修通——映点完成法、庙旺互容、火土围攻（besieged）自此真实参与判读；并配套「实时形状哨兵」防止再次静默失效。
- **围攻语义精确化**：只有火星＋土星两侧夹攻才算凶围；金星木星环护为「围荣」、日月环护为「围耀」，属吉证词，不再有误判为凶的可能。新增「围攻详断」卡展示逐星围攻/环护/协防明细。

## 卜卦盘 · 完成法与应期算法完善

- **完成法判定收紧到古典口径**：45° 等次相位不再构成完成；交点/福点不再被误当作传递/汇集的第三星；「事项主落在自己宫位」不再误判为落位完成。
- **新增多档可选口径**（默认全部保持原行为）：刑冲的接纳化解门槛（任意接纳 / 庙旺级 / 庙旺或双次尊贵）、庙旺互容独立成事、判破坏后经传递/汇集/互容「破而得救」可改判、传光候选星集（含三王星 / 仅七政）。
- **应期修复**：应期九格表（角续果 × 星座三态）补全为传统单调递进口径，杜绝「约 3.2 几乎无望」式的错误拼串；光线传递按「信使→目标」腿折算、汇集按较慢一腿折算（此前这两类完成的应期恒缺）；新增换座副应期与「临留驻」修正注记。
- **月亮升格**可选真升为主象征（四条件命中且主径无完成时，以月亮径续判、应期随之）；「月亮出本座前最后相位」现为真实计算，进「结局如何」判读。

## 卜卦盘 · 征象星语义与专题

- **「问谁的事」人称档**：问配偶 / 子女 / 父母 / 兄弟姊妹 / 朋友 / 上司 / 宠物之事时，用事宫按转宫法自动换算（如问配偶的事业＝7 起第 10＝本盘第 4 宫），征象星、根本性考量同步跟随，右栏给出转宫标注。
- **问者性别档**：婚恋类按问者性别分流对象自然征象（男问者→金星/月亮，女问者→太阳/火星）。
- **同主一星五法真执行**：法 C 真查共用星被谁容纳；法 E 以事项宫头逐度总管拆分出另一象征星。
- **问题类别扩至 20 类**：新增「走失活物」（六宫小活物 / 十二宫大牲畜，带元素方位）与「通用买卖」（1 买方 · 7 卖方 · 4 货物 · 10 价格四角）；婚姻类新增分科专题（两主接通、金星、日月配合、七宫互容专查）；失物类补福点所在、定位星与月亮方位三征。每类均配「断法要点」吉凶徵提示。
- 新增「痣记验证」卡（传统验盘法：命度/命主/六宫/月亮所落座对应身体部位）。

## 界面 · 缩放档下的版面与浮层根治

- **在非默认缩放档下,全站下拉菜单、提示气泡、日期面板等浮层会整体错位、并可能被相邻面板压住** —— 现已根治。根因是页面缩放使「量出来的位置」与「写回去的位置」分属两套坐标,浮层定位库把前者的位移直接写进了后者,偏移量随缩放比与距离放大(缩放为 1:1 时恰好为零,所以默认档一直正常)。修复对全部浮层生效,并覆盖星盘悬浮卡、曲线提示、状态徽标等自绘浮层。
- 顺带清除了紫微中栏一处会让悬浮窗被裁切的样式残留(悬浮窗「被遮挡」的另一半原因)。
- 修复自带应急开关与三级回滚,且在缩放为默认档时逻辑完全不参与运算,对既有行为零影响。
- **在非默认缩放档下,窗口底部会留出一大条空白、版面也不随窗口大小调整** —— 现已根治。
  这一条与上一条同源:页面缩放会让「量出来的尺寸」与「实际可用的版面空间」分属两套坐标,
  而不同 macOS 版本的显示引擎对此处理并不一致 —— 部分版本上量出的尺寸不随缩放变化,
  版面因此被配矮了一截,内容只铺满窗口的一部分。命盘工作区、奇门、三式合一以及启动界面
  四处都受此影响。修法改为**直接测量容器本身**,不再依赖任何缩放换算,故在各版本 macOS
  上结果一致。若你此前用「视图 → 实际大小(⌘0)」规避过这个问题,现在可以放心调回习惯的缩放档。
