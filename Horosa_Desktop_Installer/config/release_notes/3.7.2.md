# Horosa 星阙 v3.7.2

## 三式合一 · 连续进退流畅度大修

连续点击时间进退（上一时辰 / 下一时辰、上一日 / 下一日等）时的长时间卡顿彻底根治，四处病灶逐一修复：

- **连点不再丢击**：此前正在计算时的点击会被直接丢弃，出现「时间控件已经翻页、盘却没跟着算」的错位；现改为排队并在连点静默后按最新时刻补算一次（连点期间不起中间轮，只认最后一下）。
- **不再空等盘同步**：重算不再统一等待固定的 1.2 秒兜底延时，起盘请求立即发出；回流校正由重算签名去重天然兜住，正确性不变。
- **快照构建让路**：AI 挂载快照的构建改到浏览器空闲时段执行（带 4 秒超时兜底），不再插在「上一步落地 → 下一步开算」之间顶住下一次点击。
- **三盘步进预取**：选定步长后自动预算下一步的农历、奇门盘与太乙盘，连续进退全程走本地缓存命中。

同时，三式合一重算时的**全屏加载遮罩已撤除**，改为中栏右上角一枚小型「计算中」徽标——重算期间盘面与左右栏保持可读可操作，不再被整屏挡住。

## 黄历 / 农历月历 · 显示空间自适应

窗口变小或分栏调窄时，月历格子的严重失真（文字溢出、上下行叠印、内容被裁）彻底修复。新版式在**任何尺寸下都完整显示全部信息，且字号绝不因高度变化而缩小**：

- **宽度不足**：格内全部字号与间距按比例等比缩放，保证不撑破格子。
- **高度不足**：**逐级收行**——每少一档高度只多合并一行，依次为「农历并入日号行 → 日干支与建除·黄黑道·值宿并作一行 → 乌兔星并入 → 宜忌并入」，直至全部信息横向流动排布；内容始终双向居中。
- **高度充足时完整保留原有的美观纵向版式**，零改动。
- 收行等级按当前内容与格宽**现场实测**决定，不使用固定阈值：农历与老黄历两个页签内容量不同，各自独立判定，互不牵连。
