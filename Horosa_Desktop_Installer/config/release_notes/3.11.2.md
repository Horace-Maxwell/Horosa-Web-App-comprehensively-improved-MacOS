# Horosa 星阙 v3.11.2

本版是 v3.11.1 之后的性能与准确性版本:**启动更快**(界面与本地服务并行准备、温启直接显示上次的盘)、**排盘与各技法计算显著提速**(结果不变);八字 / 农历 / 节气一系列口径修正(海外出生、公元前年份、交节时刻、2033 年闰月等);六爻间爻按世应位置取;另有若干页面载入与挂载问题修复。

---

## 启动与流畅度

- **启动时界面与本地服务并行准备**:界面资源一就绪就开始加载,不再等本地服务全部就绪;服务就绪的一刻,界面里等待的请求立即放行。
- **更新后的第一次启动也提前进入界面**:启动页显示「更新已完成,正在恢复启动」与已用时,不再全程停在启动画面。
- **温启直接显示上次的盘**:再次打开软件时,按上次的时间、地点与全部排盘选项直接出盘(7 天内有效);抢先操作以你的操作为准,服务异常时回到「此刻」盘。
- **你的操作优先于后台预取**:切换参数、步进时间等前台计算排在后台预取之前。
- **一次改动只重算一次**:七政四余、太乙、巴比伦、十年大运、量化盘(90° 中点盘 / 图形星历 / 六宫框)、皇极经世、荆诀、太玄、神易数、五兆、数算等 13 个页面,此前一次改动会重算两遍;五兆同一次改动不再取两次随机种。
- **数据传输加解密改由系统原生加密接口在后台完成**(AES-GCM,带完整性校验),不再占用界面线程;同一会话的密钥只协商一次。
- **本地服务启动更快**:Java 服务组件按需初始化并在就绪后后台预热,启动器不再为脱离会话额外冷启动一个进程。
- 界面资源的预载与预热按本机实际使用频次排序;列表类界面改用稳定的元素标识,切换时少做无谓的重建。

## 计算提速(结果不变)

- **本命盘**一次计算约 38 → 17.5 ms,响应编码约 5.7 → 1.0 ms;印度盘、占星地图、地占、策天、中点盘、推运衍生盘等响应编码同步提速(印度盘 29.7 → 19.0 ms、占星地图 147 → 67 ms)。
- **生辰节气**每张新盘少算约 5.6 ms;**铁板神数** 15.5 → 3.7 ms;**蠢子数** 19.4 → 7.0 ms;**星历表** 29.6 → 22.6 ms。
- **奇门**排盘计算约 89 → 1 ms;太乙 / 六壬 / 五兆 / 神易数 / 金口诀 / 分野的六十甲子与刻表改为常量,显示层繁简转换单遍完成。
- **皇极经世**典籍正文按需读取(每次起盘传输 1.96 MB → 27 KB);**天象微年表**只取显示的前 300 条(27.8 MB → 0.44 MB,统计不变);**玄学史**首次打开更快。
- **黄历**日子馆 / 年度吉日榜换年更快:九星值日与时辰宜忌改为用到时才计算。

## 八字

- **新增「南半球月令」设置**:不对冲(默认)/ 对冲,只对南纬出生生效。此前同一张南半球命盘在不同功能里会出现两套月柱。
- **海外出生按出生的绝对时刻判交节**:非东八区出生的年柱 / 月柱 / 起运此前会偏「8 − 时区」小时(如巴黎、纽约芒种后两小时内出生仍判上一个月)。
- **「春分定卯时」按「直接时间」计算**:此前日柱可能前错一天;「直接时间」在交节后一段时间内不再报错(六壬起课不再失败)。
- **年柱**:二月立春前出生不再判成下一年;真太阳时 / 平太阳时换算跨过交节时不再报「节气窗不够」。
- **真太阳时 / 平太阳时**:经纬度「度 + 分」按分 / 60 解析(偏移此前最多差约 4 分钟);西部地点子时出生的日柱不再前错一天。
- **岁数与年份**:公元前及其他域外年份的大运 / 流年 / 小运岁数不再小一岁;旧版界面的岁数随「年龄」设置;公元前出生、行运跨到公元的盘不再出现「0 年」。
- 农历日期、节后天数、人元司令随所选时间算法取值。

## 农历与节气

- **交节时刻按节气黄经精确求解**(此前系统性晚约 12 秒),节气时刻四舍五入到秒。
- 换算后的时刻不再出现「:60」秒(整点出生的时辰此前可能判早一个)。
- **海外出生的农历日期**按北京时间编算的农历表、以出生地日期查询;东八区以外的朔时刻注明「北京时间」。
- **紫微斗数海外出生盘**随之校正:部分月份的农历日期变动一天,安星随之变化。
- **2033 年闰月为闰十一月**(此前显示闰七月,跨年前后同一个月的叫法也不一致);1642、2128 年同理;1813、2185 年不再多出闰八月。其余年份不变。
- 奇门当前节气、节气页离线计算、奇门择日、河洛出生节气按所在地的当地时间比较交节。
- 八字 / 紫微 / 黄历帮助补充阴历口径与两条算法路径的差异说明。

## 六爻

- **间爻按世应位置取**:间爻是世应中间的两爻,随世位而定(世应在初、四爻取二、三爻,在二、五爻取三、四爻,在三、上爻取四、五爻)。此前固定取三、四爻,64 卦中有 48 卦把世爻或应爻本身算进了间爻。
- 概览与 AI 分析中的间爻逐爻标出旺衰、动静、空破及与世、应的冲合生克,间爻发动时提示「事多阻隔」;帮助文档补充间爻取法。
- 「正月初一定年」在联机计算时同样生效。

## 其他修复

- **更新后立即按新版本计算**:更新完成后不再在一段时间内沿用旧版本缓存的排盘结果(本版各项口径修正在更新后立即生效)。
- 启动过程中点「重启后端」不再与正在进行的启动重复拉起本地服务。
- 玄学史「故事专题」首次打开不再一直显示「载入…」;神数正传切换流派后条文正常载入;玄学史人物关系图每次打开布局一致。
- 玄学史天象库统一为「史料所载的儒略历日期」一种约定,「排此日」起盘不再早 3~7 天;84 条年号 / 干支日期按原始记载重新推算。
- AI 分析挂载的「小限粒度 / 小限起点」对命盘生效。
- 缩放上限随窗口宽度封顶:小窗口极大缩放时三栏页主盘不再被挤没,窗口变窄时自动降到上限并提示原因。
- AI 助手设置移除无作用的「配色主题」项。
- 本地服务日志不再记录 AI 分析相关请求,密钥类参数一律脱敏。
- 生辰节气「卯时按黄经」在高纬地区不再卡住。
- 界面的本地端口被占用(如另一个实例正在运行)时顺延到相邻端口、不再随机换口,本地保存的偏好与缓存不会因此看起来被清空。
