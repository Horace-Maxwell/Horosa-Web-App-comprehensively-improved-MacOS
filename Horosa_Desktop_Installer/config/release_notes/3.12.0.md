# Horosa 星阙 v3.12.0

本版是 v3.11.3 之后的一个大版本:**界面可一键切换繁体**;AI 对话可以同时挂本人与合盘对方两张命盘,并给出八字合婚与紫微合盘对照;外部连接扩展为本机 MCP 读写、REST 接口、终端命令与不开 App 的无头模式(相关开关默认关闭);历法上把 **1582 年以前与公元前的盘**在各技法里逐一校正;另有全站文字对比度、放大档版面、旧系统兼容的收口,以及数据存储与备份恢复的一批稳健性修正。**会改变已有盘结果的地方,各节里都标了「结果会变」。**

---

## 本版新增

- **界面简繁切换**:设置菜单「全局设置」与「关于星阙」之间新增「切换繁体 / 切换简体」,点一下整个界面简繁互换。术数用字按语境逐字定字(如干支的「干」、生克的「剋」、社稷「后土」与「後來」),菜单栏、系统对话框、启动页 / 偏好设置 / 诊断中心窗口一并跟随;导出、截图和发给 AI 的内容始终是简体。繁体界面下照屏幕输入繁体、直接输入简体或简繁混输都能搜到。
- **AI 对话双盘挂载**:可同时挂本人与合盘对方两张命盘(挂载抽屉「合盘对方」、第二个 `@命盘`、`/合盘 名字` 三个入口),每个技法两人各挂一层并注明归属;西洋比较盘 / 组合盘 / 影响盘 / 契合度进入对话上下文,追问不丢。两人都挂八字时给出八字合婚对照(年命冲合刑害与纳音生克、日柱夫妻宫、喜忌互补),都挂紫微时给出紫微合盘对照(双方生年四化落入对方哪一宫、命宫与夫妻宫主星,四化按各自盘的流派);只列对照事实,不打分。八字合婚对照另有四柱逐柱对照(年 / 月 / 日 / 时同柱的天干合冲、地支六合 / 三合 / 六冲 / 相刑 / 六害)与「两人地支合局」(两人地支合起来才齐的三合局 / 三会局 / 三刑,写明每支出自谁的哪一柱);紫微合盘对照另有双方命宫 / 身宫落在对方哪一宫(命身同宫会注明),四化入宫带上落宫地支。
- **AI 对话命令更顺手**:新增 `/help`;命令参数里的 `@` 与正文同一解析;年份可写 2027、2027年、二〇二七、明年、后年;技能包里的技法只作用于这一轮,不再替换会话原有挂载;你的消息气泡显示命令芯片与「本轮按 …」;命令参数有补全菜单。「按任务用模型」新增辅助槽(压缩对话、生成口径、记忆提炼、自动起标题),空着即跟随当前模型。
- **命主实况**:命盘问卷改名「命主实况」,可按命盘决定是否发给 AI(缺省不发),开着时连同这张盘的断事日志一起发送;命主工作区可直接编辑。
- **外部连接(默认关)**:
  - 本机 MCP 可读的内容补齐:后台任务、合盘取数(西洋 / 八字合婚 / 紫微合盘)、天星择日、玄学史检索与全文、当前页 AI 导出正文;对话记录、档案备注与断事日志另有「私人内容可读」开关,缺省关。
  - 外部 AI 可按你的要求:把你报出的起卦结果存成事盘(六爻 / 小六壬 / 灵棋 / 统摄法 / 小成图 / 飞宫,只用你给的结果,不随机代起)、追加断事日志、记两张档案的关系、设置对话挂载、修改技法页保存的排盘设置、按各流派择日(黄历 / 八字 / 紫微 / 六壬 / 太乙 / 七政 / 印度 / 奇门)并逐条说明合与不合。
  - AI 改档案或归档只能**提议**:提案进任务中心,逐字段显示原值与新值,你采纳才改,采纳后可撤销;删除永不开放。
  - 新开关「界面类也要确认」:打开后外部程序切换技法页、合盘配对、设置对话挂载前也要你在本机确认。
  - 新增本机 **REST 接口** `/api/v1`(缺省关,与 MCP 同一令牌、同一套工具与审批);新增**终端命令 `horosa`**(进阶页「外部连接」一键安装到 `~/.local/bin`)。
- **无头模式**:源码仓库根目录的 `./horosa` 可以不开 App 使用全部 AI 工具(终端、MCP、REST),数据存放在 `~/.horosa`;可配置模型接口做分析(密钥隐藏输入、加密存放,命令行参数里给密钥一律拒收);`./horosa export` / `import` 与桌面「全量备份」同一格式;改设置、采纳提案、导入导出用单独的管理令牌;`./horosa undo` 撤销外部写入。
- **名人库开放给 AI**:约 5.9 万位名人可检索、看详情、一键存成命盘后起盘,引用保留来源;AI 建档另记名人库编号,档案改名后也不会建第二条。
- **紫微排盘设置随盘保存**:存盘时记下这张盘的紫微设置,载入时按盘起盘;你亲手设的偏好另存一份,「新命盘」时用回(此前载入一张盘就会永久改写偏好)。
- **塔罗牌面缺省改为「真实牌面」**:牌面图随软件打包、离线可用;没有真实牌面的牌组与缺图的牌照旧回退符号;深色主题下塔罗左右两栏与其他页侧栏同款。
- **帮助按页内技法切换**:演禽、策天飞星、一掌经等合页的帮助按你当前所在的技法打开对应手册。
- **技法批量验证**:`./horosa batch` 对一批命例 × 一组技法逐例起盘,一行一例写 JSONL 并出汇总;支持断点续跑、并发数、多套计算服务,单例失败只记一行错误;可直接以内置名人库(约 5.9 万例)为输入。`./horosa batch-pack` 打一个可在 Linux 服务器上运行的运行包(只需 Node 18+ 与 Python 3.11+,要 Java 的技法另需 JDK 17;含起停脚本与 Dockerfile)。批量结果与单例无头起盘同一引擎、同一设置,逐值一致。
- 无头:配的计算服务端口连不上时不再悄悄改用桌面 App 的后端;`./horosa call … --json` 接管道时的大回包不再被截断;起盘源的时区可带秒(地方平时),给经纬度时可附出生地名。巴比伦占星在计算服务没回行星位置时如实报起盘失败。

## 历法与历史盘(1582 年以前 / 公元前)

本版把「1582-10-15 格里历改历以前用儒略历、公元前用天文纪年换算」的口径落实到各技法。**1582-10-15 以后出生的盘,除下文单独注明的条目外不受影响。**

**显示口径**
- 推运、返照、星历事件、天狼偕日升、择日命中、占星地图事件时刻、天文馆、日月食等的日期:1582 年以前改为儒略历,公元前改为历史纪年(没有公元 0 年)。
- 公元前的盘:推运主页的返照、月返、流年、小限、太阳弧、行星弧、波斯向运都能选公元前目标日出盘(此前报参数错);年表跨公元元年时不再多出一行「0 年」;年份补足四位显示(如 `-0002-03-10`、`0050-…`);目标日初值改为今年的生日(此前出现「20263 年」这类年份);公元前闰年可选 2 月 29 日;时刻不再显示成 `HH:mm:60`,公元前远古时刻不再成镜像。
- 主限法表格的「年龄」列对公元前的盘也能算出(此前显示「—」)。
- 行星年龄、月相周期、三分主星、波斯向运、关键点、校时预览:公元前 / 两位年 / 五位年出生的年龄与日期标签改正。
- 通书、八字流日、紫微流日:1500 年 2 月有 29 日,1582 年 10 月不再出现 5–14 日。
- 东八区下公元前、五位年、斜杠或带时刻写法的命盘,按天推进的推运日期不再少一天;「中国统一北京时间」对公元前与公元 1–999 年的盘保留当地时区。
- CSV 导入能导回本软件自己导出的公元前 / 公元 1–999 年 / 五位年生辰。

**结果会变**
- **西洋推运与返照**:1582 年以前出生的二次 / 三次 / 小限推运、太阳 / 月亮返照(含 AI 挂载与世俗盘)改为正确值 —— 此前 1500 年出生的盘二次推运约差十年、返照晚 10 天,公元前返照差约一年。世俗页点选公元前的会合起盘不再早一年。
- **小限 / 太阳弧 / 行星弧年表**:1582 年以前出生、年表跨过 1582 年的行,日期标签晚 10 天(如 1583-05-10 → 1583-05-20);小限这些行由只转 29.17° 改为整 30°,本命点接近星座起点的,这些行的小限座会变。2 月 29 日出生的年表在平年显示为 3 月 1 日(盘体本来就按 3 月 1 日算,不变)。
- **小限年表(现代盘也受影响)**:周年日恰在太阳回归前后数分钟的行(约 1%,常见于第 33 / 66 / 99 行)此前整盘多转或少转 30°(小限座错一宫),现已改正。
- **十年大运**(1582 年以前、公元前出生):时间线落在正确的年份,「当前所处」随之正确;期界日期按儒略历标注,公元前带负号;1500-02-29 这类儒略闰日不再挪到 3 月 1 日。现代命盘不变。
- **八字与本地历算**(含六壬、奇门、三式择日扫描):1582 年以前世纪年 2 月 29 日与跨日校正的日柱改正;1582-10-04 深夜往东不再报错;1582 年以前真太阳时的均时差按真实日期计算,相差数秒到数十秒。
- **1582 年以前 2 月 29 日出生**(1500、1300、1000 年等):邵子、铁板、分金、北极、南极、蠢子、策天、先秦、七政「坚七政」样式此前按当月 1 日排盘,现在按当天排(四柱、星位会变);主限法推运表此前直接失败,现在能出。
- **公元前出生**:印占年盘年龄 / Muntha / 年主,以及过运、年盘、三旗、问时、阴历返照盘改正(此前被当成另一年);策天、仙禽、蠢子的农历年与年柱改正(此前整差一年)。
- **印占大运**:1582 年以前前端自建的大运子段整体平移约 10 天;公元前大运日期显示为历史纪年加儒略历(此前差一年);小运以下的起讫精确到时分。
- **七政果老**:1582 年以前的出生盘按儒略历起盘(此前差 7–10 天、太阳差 7–10°);公元前、公元 1–999 年、五位年的盘此前会整盘落到 2025-01-01,现在按实际日期起盘;择日 / 流时的日期改为民用历。
- **七政 Moira 轮盘**:百六大限在 1582 年以前岁末(约 10 天内)或立春 / 冬至附近出生的盘,年界与岁次按儒略历计,大限岁数可能变动一岁;公元前冬月出生的盘,带「冬」条件的格局(如「金水相涵」)按冬令判定。七政宿度郑氏恒星制在公元前的岁差改正约 50″。
- **太乙 / 三式合一**:公元前、公元 1–99 年与 1582 年以前的日 / 时 / 分计积数改正;另外 1900-12-21 以前(日计为 1900-06-19 以前)、钟点不在 00 点的盘,时计 / 日计 / 分计的积日此前少算一天,局、太乙、文昌、主客算随之改变(时计差 12 局号),分计在 00 点后几分钟也会变。太乙 / 三式择日扫描 1900 年以前的时段,所判与点开所见从此一致。三式合一、太乙择日与 AI 挂载同步。
- **奇门**:公元 1–99 年的当前节气与局改正;太乙 / 奇门 / 皇极在 1300、1500 等儒略历世纪闰年的 2 月 29 日能起盘(此前报错),奇门置闰 / 无闰的距符头天数跨这类日子不再差一天。
- **太玄**:起筮支持 2100 年及以后;1900 年以前与公元前的「农历」「冬至起算」显示当年真值(此前显示成 1900 年);1900-01-01 至 12-21 之间「冬至起算」由 1899-12-21 改为 1899-12-22,天数少 1,卦不变。
- **择日**:1582 年以前逐时辰 / 逐日扫描补上儒略闰日,不再扫改历缺口里的 10 天;六壬择日 1582 年以前的昼夜贵人边界按真实季节算(约移动十天的日出差)。
- **不存在的日期**(1582-10-05 至 10-14、2 月 30 日、公元 0 年):太乙、奇门、皇极、金口诀、五兆、神易数与全部择日(含 AI 择日工具)一律提示「日期不存在」,此前部分入口会按别的日子起盘或判成「结束早于开始」。

## 命

**八字与数算**
- **结果会变**:八字「节气按纬度调整」停用,一律按 0 处理;此前存过 1 的老命盘,若纬度在 23.5°–66.5° 之间且出生在节气前后约 |(|纬度|−35)×2| 天内,月柱(近立春时还有年柱)与大运会变。
- 起运精度「整数」档:不足半年时显示「出生后不足1年起运」(此前强写约 1 年)。
- **结果会变**:邵子、铁板、分金、北极、南极、蠢子、策天等页改按本盘的「子时四态」取值(与八字页、AI 挂载一致,此前恒读全局);本盘值与全局不同且出生在 23 点档时,日柱 / 时柱随本盘。
- **结果会变**:蠢子数「自动刻」改按时辰内位置推刻,偶数点出生者的「刻」会变(6–10 刻),条文候选不变。
- 南极神数新开页面的「推演宫」初值改为「自出(宫部首支)」,与 AI 挂载一致;已存事盘里选过的推演宫不变。
- 一掌经预设名「程序通行」改为「通行简法」。
- 八字大运流年紧凑面板在小窗或放大档下不再被截掉最后一排。

**西洋占星**
- **结果会变(极区)**:出生在极圈内、且本时刻子午线上中天交点在地平以下时,MC 不再随分宫制变,一律取上中天交点,盘面信息卡与 AI 快照标「极区天顶」。此前选 Regiomontanus / Campanus / Polich-Page / APC / Sunshine 时 MC 与其他宫制差 180°,MC 相位与落宫都会不同;这几种宫制的宫头不变,所以 10 宫头可能与 MC 不同(徽记说明里写明)。非极区盘逐位不变。
- **结果会变**:组合盘回落整宫或使用整宫类宫制时,改为用整宫制重建两盘再取中点 —— 宫位、落宫与盘头宫制名都是真整宫(此前上升可能落进第 2 宫)。
- 合盘左栏流派预设(黄道 / 分宫制 / 界系 / 三分 / 点反转 / 区分缓冲)连同相位口径与点公式一起写进合盘并即时重排,下拉不再跳「自定」。合盘未选齐两张盘时,右栏各页签提示「先在上方选择星盘 A 与星盘 B」,不再整页报错。
- **量化盘**:AI 分析与导出新增「赤纬接触」段,缺省(原始汉堡派、无其他汉堡开关)也附平行 / 反平行全表,与 90° 中点盘右栏一致,**缺省量化盘快照内容会变多**,关掉「赤纬接触」即不附;自定义过导出段的用户升级后自动勾上这一新段(只补这一段)。在 90° 盘改流派 / 容许度 / 赤纬 / 六宫框 / 东点 / 严格因子集 / 戴维森后,中点页重新取数。原始汉堡派图形星历的盘基改为 90°(与图形星历页缺省一致)。
- **结果会变(非东八区的盘)**:推运类缺省目标时刻(小限、太阳弧、行星弧、波斯向运、主限法盘、七政四余与量化盘行运「此刻」)与二次 / 恒星 / 赤纬推运、星历、回归轴、印占过运日与年度盘的缺省「今日 / 今年」,改为按这张盘所用的时区换算真实此刻;此前差了时差那么多小时,跨日时差一天。东八区的盘不变。AI 挂载与无头起盘同一口径;无头起课没给时间时按起课地时区取此刻。
- 黄道星释:换一张命盘后,中栏先显示新命主的本命盘,整宫制专盘取到后再换上(此前会一直显示上一个人的整宫盘)。
- 返照、太阳弧、月返、小限、流年、行星弧、波斯向运、推运双盘:换了命主后,新推运盘到达之前不再画上一位命主的推运圈,取失败时也不画旧人的盘;同一位命主只改设置时仍是「旧盘留存 + 更新中」。
- 快速连点或换盘时,黄道星释整宫专盘、世俗盘食时长、西洋择日候选扫描、七政方位 / 日月食搜索、埃及历偕日升不再出现「先发的结果晚到、盖掉后发的」。
- 主限表「计算」与主限盘请求不再互相吞结果;主限法步进时的预取重新生效,步进恢复秒回。

**七政四余**
- **结果会变**:全局「行星时制式」改过的用户,报时星结果可能变;缺省制式下左栏「报时星」置灰。
- 本次运行内后来新开的盘按本机保存的口径起盘;首开不再把本机保存的自定命宫播给新盘;恒星岁差空档显示「随本机(档名)」。
- 宿度制缺省全站统一(七政首开、推运、AI 挂载与新盘同一个缺省值);你此前存过的宿度制维持不变。
- 换命主后本命盘取失败时,不再画上一位命主的盘。

**印占**

**记录与事盘**
- **结果会变**:左栏亲手改的日界 / 晚子时只对那张盘生效(重启后仍在那张盘上);载入别的盘、点「此刻」、新命盘或载入另一课后,重新跟随「设置 → 日界」。
- 页面「新增命盘」的随盘设置改为新命盘缺省(此前抄当前盘面,刚载入过别人的盘就串进来)。当前命盘被删或合并进回收站后,盘留在屏幕上但不再关联那条记录(「保存」另存新记录)。

- 多窗口:在一个窗口置顶、加星、排序、改备注、加标签、记日志、建关联,另一个窗口正在看的盘不再整页重新还原或重排;在一个窗口改日界 / 晚子时,另一窗口的当前盘按新口径重排;别的窗口改了命盘名或地名、删除或修改了当前盘,本窗口跟着更新。

**存储吃紧与损坏**
- 存储满又碰上某项数据(择日方案、书签等)读不出来时,原内容不再被删:这一项暂停写入,横幅提示,可在「存储健康」导出原内容或放弃那份损坏内容立即恢复写入;腾出空间后自动另存留档并恢复写入。AI 挂载卡与工具箱表单不再反复被清空。
- 世俗自建地区、地占历史、命主实况问卷等数据损坏后,原内容先另存一份,不再被下一次保存静默盖掉;保存失败如实提示。存储满时,命主实况发送开关、人设、模型路由不再显示「已保存」却没生效;七政 / 埃及流派等设置在存储告急时先清缓存再写。
- AI 工作区数据库偶尔打不开时,不再整次运行锁在内存模式:稍后自动重试,重新打开后这段时间新建的对话并回数据库,列表不再丢失或显示为空;这段时间里「恢复 AI 工作区」会提示稍后再试。
- 后端回包里带业务错误的结果不再进任何缓存(包括跨重启的持久缓存),七政 / 八字 / 3D 盘等不再把一次偶发错误缓存到重启。
- **后端写出的请求记录统一隐去密钥**:交易日志、数据库不可用时的本地回落缓存、错误日志里的请求数据 / 查询串 / 出站请求头与网址,供应商密钥、令牌、口令类字段一律写成 `***`(含嵌套对象、请求头、网址查询串、错误文字)。日志掩码统一为 `***`;AI 报错文字里嵌着的 key / token / password 类字段同样显示为 `***`。
