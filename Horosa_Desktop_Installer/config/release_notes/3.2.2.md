# v3.2.2
- 软件内更新体验全面升级:检查更新即显示本次需下载的体积与增量复用率;下载全程显示已下载字节/速度/预计剩余时间与部件进度;安装阶段(克隆/解压/切换)全程可见,不再有任何黑盒等待。
- 更新下载支持断点续传:网络中断或中途退出后再次更新自动从断点继续,不再从零重下;下载文件原子落盘,绝不出现半成品。
- 菜单「检查更新」并入增量通道:常规版本更新只需下载变化部件(约数十 MB),不再固定全量下载。
- 更新自愈:更新后若连续两次启动失败,自动回滚到上一版本继续可用,并可从菜单重试更新。
- 启动与响应性能:后端服务启动阶段精简(卜类服务改为按需装载并在就绪后空闲预热),启动更快;修复内置 Java 运行时 AppCDS 加速链路自始未生效的问题,并在安装包内预置加速档案,首次启动即生效;高频技法结果缓存加强,来回切换设置近乎即时;导航悬停即预载对应模块。
- 修复:特定安装环境下太乙服务可能加载失败且无提示的问题,现改为按需装载+失败醒目报错,并有启动预热兜底。
- 更新过程事件全程记录在本地日志,出现问题可凭日志快速定位(纯本地,零上传)。
- 运行时随版本号同步为 3.2.2-runtime1。
